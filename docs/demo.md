# 三分钟演示脚本

演示前启动本地服务，使用干净浏览器上下文或选择「午间休憩 · v1」。页面右上角应明确显示「本地模板模式」；如果使用真实模型，提前单独验证服务可用性。

| 时间      | 操作                           | 讲述重点                                                                     |
| --------- | ------------------------------ | ---------------------------------------------------------------------------- |
| 0:00–0:20 | 展示中文工作台和需求输入       | CabinLab 帮助座舱团队把自然语言需求变成可检查的自动化，并先在虚拟台架验证    |
| 0:20–0:50 | 点击生成，查看确认卡           | 停车怎么定义？多热、持续多久？退出是否恢复？模型或模板提供建议，用户确认约定 |
| 0:50–1:15 | 保存并开始预演                 | 时间满足后先发出请求，再出现状态回读；接受请求不代表设备状态达成             |
| 1:15–1:45 | 选择目标温度超时，重新运行     | 显示部分完成；温控失败，媒体继续。用户也可以手动接管，自动化不抢回控制       |
| 1:45–2:20 | 运行 20 项验证                 | 用独立的产品预期检查正常路径、边界、守卫、超时、接管和重放                   |
| 2:20–2:45 | 持续时间改为 0，确认、再次验证 | 同一套测试发现短时波动误触发；测试答案没有跟着错误版本一起变                 |
| 2:45–3:00 | 切回 v1 并验证，导出实验       | 场景版本、输入、事件、断言结果一并留痕，问题可以复现                         |

建议结尾：**我们不只让 AI 会生成场景，也让人知道它何时会执行、为何失败，以及如何重现。**

当前本地模板模式只做关键词推荐，不能在讲解中称其为实时模型推理。所有动作是模拟，验证结果不代表真车安全认证。录制视频、部署体验链接、提交比赛材料需要另行完成。
