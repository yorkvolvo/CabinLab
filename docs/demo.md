# 三分钟演示脚本

演示前启动本地服务，使用干净浏览器上下文或选择「午间休憩 · v1」。页面右上角应明确显示「本地模板模式」；如果使用真实模型，提前单独验证服务可用性。

| 时间      | 操作                                                                          | 讲述重点                                                                    |
| --------- | ----------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 0:00–0:20 | 展示工作台和模式标识                                                          | 一句话编排、虚拟预演、独立验证；说明当前是可复现的本地演示，不冒充模型推理  |
| 0:20–0:45 | 点击生成，核对并确认草案                                                      | 明确停车定义、温度与持续时间，以及退出只停止后续动作的约定                  |
| 0:45–1:10 | 开始预演，完成后导出运行证据                                                  | 先有请求接受，再有状态回读；保存文件，后面跨会话复现                        |
| 1:10–1:35 | 注入目标温度超时，重新预演                                                    | 结果是部分完成，媒体继续，失败有明确证据；已接受不等于已成功                |
| 1:35–2:25 | 修改当前场景，输入「把持续时间改为 0 秒」；确认差异，展开版本对照并与 v1 验证 | 明确基于哪个版本修改，10→0；同一独立断言集从22/22变为14/22，显示8项新增失败 |
| 2:25–3:00 | 打开证据复核，导入正常运行的文件，展开事件                                    | 输入、场景版本、事件和终态独立重放；核验一致不代表来源认证或真车安全认证    |

建议结尾：**我们不只让 AI 会生成场景，也让人知道它何时会执行、为何失败，以及如何重现。**

当前本地创建只做关键词推荐，修改只解析完整匹配的参数句式，不能称其为实时模型推理。真实模型适配器已做 mock 合约测试，但没有真实厂商凭证验收。所有动作均为模拟。

备用演示：输入「持续时间改为 5 秒，打开车窗」，展示整次拒绝且原参数未变；或者修改导出 JSON 的终态温度，再导入，展示一致性核验失败。错误文件不会覆盖当前场景。录制视频、部署体验链接、提交比赛材料仍需另行完成。
